# Model Addressing Modes

Three modes:

1. Orchestrated virtual profiles (forgegate/fast, balanced, smart, coding) — selects logical model + provider route based on health, quotas, latency, capacity, task.
2. Logical model routing (model/minimax-m2.7) — fixed logical model, provider may vary for failover.
3. Direct provider/model (direct/xkiro/minimax-m2.7) — fixed provider + model; for debugging/comparison. Does NOT bypass logging, policy, supervision, audit.
