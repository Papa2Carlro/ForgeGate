# MVP Boundary

Do NOT implement all 30 rules in MVP.

MVP establishes extensible concepts: activity events; evidence; execution signals; policy decisions; completion assessment; task/session context.

Initial high-value subset: unsafe git/worktree protection; invalid certification detection; BLOCKED-vs-NOT_RUN validation; repeated-read/repeated-command signals; long-running-command awareness; cross-session mutation protection; completion evidence validation.

Additional patterns added incrementally.
