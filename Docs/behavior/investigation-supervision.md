# Investigation Supervision

Anti-patterns: repeated instrumentation without narrowing unknown; revisiting closed causal boundaries; multiple hypotheses in one slice; inventing fixes before root cause proven; using observation channel already known inaccessible.

Principles: one narrow question per diagnostic slice; one hypothesis per slice; preserve closed facts; change observation channel when current cannot be observed; do not authorize production fix when ROOT_CAUSE is NOT_PROVEN.
