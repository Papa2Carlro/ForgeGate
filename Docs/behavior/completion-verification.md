# Completion Verification

Distinct conceptual concern (separate from routing, policy, planning, workspace coordination).

Before accepting agent completion, evaluate: was action executed? Is evidence direct or inferred? Is PASS supported by real command/runtime output? Was runtime proof incorrectly inferred from code/tests? Is root cause uniquely proven? Unresolved alternatives present? Focused test skipped? Unsafe git operations used? Did agent answer exact current task boundary?
