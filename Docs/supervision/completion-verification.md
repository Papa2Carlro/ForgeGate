# Completion Verification

Separate concern from Action Policy. Selectively verifies high-value final claims/statuses: PASS; PARTIAL_PASS; BLOCKED; NOT_PROVEN; "root cause proven"; "runtime verified"; "all tests pass"; "issue fixed"; "no production changes"; "historical parity preserved"; equivalent task-completion claims. Phrase matcher must NOT be hardcoded from docs alone. Goal: detect claims requiring evidence.
