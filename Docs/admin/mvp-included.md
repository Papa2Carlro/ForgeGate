# Admin MVP — Included

Dashboard (provider health, active requests/sessions, rate-limit/quota, routing activity, recent failures). Providers (configured, enable/disable, endpoint, credential reference, declared capabilities/limits, health/state). Models/Routes (configured/discovered, logical models, provider routes, enable/disable, coarse quality/priority). Routing Profiles (fast, balanced, smart, coding; quality floor; wait/degrade). Policies/Supervision (enable/disable initial rules, supervision presets, coarse strictness, model behavior profile). Activity/Audit (filter by workspace/session/provider/model/tool; attempts; routing/failover; policy decisions; completion assessments; failures).

Defines product direction, not requirement to build every screen before gateway works.
