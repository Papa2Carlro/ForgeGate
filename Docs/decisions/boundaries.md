# Architectural Boundaries

Preserve independent concerns: Provider Adapter; Provider/Model Capability Model; Provider Runtime State; Routing; Failure Normalization; Session Resolution; Workspace Coordination; Activity/Audit; Persistence; Policy Enforcement; Execution Supervision; Task Management; Completion Verification; Secret Management; Admin Control Plane.

Collaborate through explicit application boundaries/signals. Do NOT collapse into one central Orchestrator/God Service.
